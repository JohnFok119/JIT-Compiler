    Under the hood
    
The engine reads the formula, builds a tree, simplifies it without changing any result, then writes machine code. The browser can't run x86-64, so it runs the WebAssembly version.

    

    

    


    
Speed test on a plain-arithmetic formula: ((3*x - 2)*x + 5)*x - 1

    

      
      

    

    
Both run in your browser. Built-in functions like sin and exp run in JavaScript for both, so formulas made of them gain less. On a laptop processor, the native compiler is 14–21× faster on plain arithmetic.
